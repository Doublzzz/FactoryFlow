FactoryFlow 工厂离线版 — 首次安装和日常操作

适用：Windows 10 / 11，64 位；使用 Chrome 或新版 Edge。目标电脑不需要联网、Python、Node.js 或另装数据库。
本包为本机使用，不提供局域网多人访问。

1. 把整个 ZIP 复制到工厂电脑，右键“全部解压”。不要在 ZIP 内直接双击运行。
2. 双击“安装.cmd”，阅读随包 Microsoft 组件条款并在同意后输入 Y。校验和复制需要一些时间，完成后桌面出现“FactoryFlow 工厂软件”。
3. 双击桌面入口。第一次输入工厂名称、账号和密码；密码至少 12 个字符，输入时不会显示。
4. 浏览器打开后，用刚才设置的账号登录。录单时可新建客户，物料表可单独导入。
5. 完成订单确认、送货后，可做对账、导出 Excel，登记发送与客户反馈，最后形成正式结算单。

可用功能
客户、订单录入与来源文件提取、人工复核和确认、分批送货与打印、可选成品库存、对账草稿、客户 Excel 模板导入、客户外部送货/退货单号、发送/反馈/认可/待结算/待核对/正式结算、导出及本机归档。
图片识别已随包携带本地模型，不上传图片；识别结果仍需人工核对。外部退货单号是对账凭据字段，不会自动登记退货库存或负数量。
客户模板在对账编辑器中自行导入；本安装包不含真实客户模板或开发机数据。模板映射了“客户外部送货／退货单号”后，必须先填该号码才能导出。
每张订单明确选择 CNY 或 USD，默认 CNY，与界面语言无关；确认后不能改币种。同客户同期间的不同币种分别对账，不做汇率换算。客户自有模板中的币种文字仍需人工核对。
英文用户从 Install.cmd 安装，使用英文桌面入口；Read me.txt 提供英文说明。切换语言不翻译客户原文、自有模板或已保存的送货版式文字，也不改写历史导出及归档。

可选成品库存
按实物盘点数为每个成品开账；未开账表示尚无库存记录，不等于零库存。历史送货不会追溯扣库。
后续登记成品入库和盘点。送货时选择扣库或明确跳过并留待核对；不足时须再次确认，才允许账面库存为负。作废送货会冲回该单原来的库存流水。
不启用库存也可继续订单、送货和对账。本预览不含原材料、采购、生产/BOM、多仓或成本核算。

每天如何使用
直接双击桌面入口。再次启动会继续使用已有业务数据。
关闭浏览器前请保存录入；已确认保存的记录会保留。下班前可打开 %LOCALAPPDATA%\FactoryFlow，运行“备份工厂数据.cmd”，再运行“停止工厂软件.cmd”。
“查看运行状态.cmd”会显示本机网址和数据目录；如果没有自动打开浏览器，请复制网址到 Chrome。

备份和换电脑
“备份工厂数据.cmd”完成后会显示备份文件夹路径。把整个文件夹复制到 U 盘，其中包括 database.dump、manifest.json 和 objects 文件夹，缺一不可。
新电脑先安装本包；不必先建账号，直接在 %LOCALAPPDATA%\FactoryFlow 运行“恢复工厂备份.cmd”，输入备份文件夹完整路径。
恢复会建立新数据目录，验证成功后切换，原数据保留。恢复后用原账号和密码登录，旧登录会话失效。
数据目录：%LOCALAPPDATA%\FactoryFlow\data。不要把删除程序目录当成备份，也不要删除 data 文件夹。
备份和归档包含业务资料，应与原始订单文件一样妥善保管。归档目录的副本可从已恢复记录重新生成，备份保存原始证据对象。

常见情况
若提示缺少 MSVCP / VCRUNTIME，且包内带“运行库\VC_redist.x64.exe”，双击安装后重试。若未附带，可在联网电脑从下方 Microsoft 官方链接下载 x64 运行库，复制到目标电脑安装。Windows 可能要求管理员确认。
若提示端口占用，先运行“停止工厂软件”再启动；不要结束其他软件或数据库进程。
若启动失败，请保留界面提示及 data\environments 下对应目录的 server.log / postgres.log，联系维护人员。不要为了重试删除业务目录。
如果是 Windows 7/8、32 位或 ARM 设备，这个 x64 包不适用，先核实系统再安装。

验证范围
交付时以同目录的交付检查报告为准。本机已验证移动目录、隔离开发环境、无需下载即可运行；这不等于工厂电脑现场验收。请先自己新增一笔小订单，核对送货、对账、导出和备份后再批量录入。
