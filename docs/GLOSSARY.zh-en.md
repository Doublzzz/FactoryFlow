# 中英文术语表 / Chinese–English glossary

本表固定产品文案含义；不翻译用户录入的客户名、料号、品名、备注、原件及客户模板文字。英文不改变 CNY、数量单位规范值或现有业务规则。

| 中文 | English | 含义 / Boundary |
|---|---|---|
| 交有数 | FactoryFlow | 英文界面品牌名 |
| 待交清单 | Open orders | 仍有数量待交的订单明细 |
| 订单 | Order | 人工确认后的客户订货记录 |
| 客户订单号 | Customer PO number | 客户提供的订单号码，不等于系统内部 ID |
| 原件 | Source document | 上传的原始图片或 PDF |
| 提取候选 | Extraction candidate | OCR 建议，须人工核对 |
| 订单修订 | Order revision | 保留前版本的更改 |
| 物料池 | Item catalog | 物料身份资料，不表示库存 |
| 我方料号 | Internal item code | 工厂自己的物料标识 |
| 客户料号 | Customer item code | 某客户使用的物料标识 |
| 品名 | Item name | 用户提供的货物名称 |
| 规格 | Specification | 用户提供的规格文字 |
| 送货 | Delivery | 已登记的货物交付事实 |
| 送货单 | Delivery note | 交付凭证，不是发票 |
| 已交数量 | Delivered quantity | 有效送货累计数量 |
| 待交数量 | Remaining quantity | 订单数量减有效已交数量 |
| 作废 | Void | 使当前记录失效并按既有规则回退，保留证据 |
| 客户对账 | Customer reconciliation | 与客户核对交付、数量、价格及调整 |
| 对账单 | Reconciliation statement | 界面上下文清楚时简称 Statement；不使用 Invoice |
| 对账草稿 | Draft statement | 可以修改、尚未正式固定的版本 |
| 已发送 | Sent | 人工记录发送依据，产品不自动向客户发消息 |
| 客户反馈 | Customer feedback | 有来源依据的人工记录 |
| 认可数量 | Accepted quantity | 客户已认可的数量，不代表已付款 |
| 待核对 | Pending review | 尚需查证或与客户确认 |
| 暂缓 | Deferred | 本期暂不计入 |
| 本期结算 | This-period reconciliation | 本期选定处理的数量；无收付款含义 |
| 正式结算 | Finalize reconciliation | 固定本期认可数量和金额证据，不使用 Paid |
| 正式对账单 | Final statement | 已正式固定的对账版本 |
| 跨期承接 | Carry forward | 在后一期处理已认可或待核对的余量 |
| 释放 | Release | 解除本期占用，按现有规则回到可用余量 |
| 调整项 | Adjustment | 有类型与原因的金额调整 |
| 外部送货／退货单号 | External delivery / return number | 用户录入的客户凭证号；不表示系统已有退货模块 |
| 待定价 | Price pending | 缺少单价，金额留空，不能当作零 |
| 含税价，不另加税 | Tax included | 现有计算模式，不另加税额 |
| 未税最终价，不另加税 | No additional tax | 现有最终价模式，不声称海外免税资格 |
| 未税价，另加税 | Add tax | 按显式税率计算，不推断地区税法 |
| 对账币种 | Reconciliation currency | 当前只支持 CNY |
| 客户模板 | Customer template | 用户上传并人工映射的 Excel 模板 |
| 文件整理 | Working files | 工作副本整理；不替代数据库与原文件备份 |
| 历史版本 | Historical version | 固定的早期证据，不随语言切换重写 |
| 只读 | Read only | 可查询；业务写入仍受服务端权限控制 |

英文日期按所选界面语言显示；存储仍采用原有 ISO 值。单位规范值（如 PCS、KG、M）保持不变。英文输出只调整明确的系统文案，不换算单位或金额。
