## 建议演示主线

1. 先展示空待交清单；上传一种语言的PDF/PNG，提取后人工核对。PDF/PNG可作README插图，CSV只是参考明细，不代表订单CSV导入已实现。
2. 人工选择或新建明确标记的合成客户，核对四行后确认。总金额为2949.20 CNY，不能混加四行不同单位的数量。
3. 分别送30 PCS、80 PCS、10.25 KG和12 M；余量依次为90、160、25.25和36。按本例单价，本次金额为784.40 CNY。
4. 对这次送货制作对账草稿、导出英文/中文Excel，再按真实界面记录客户反馈。客户认可和正式结算都不代表付款。
5. 若演示作废，使用独立分支场景：尚未被结算占用的送货作废后恢复原余量。不要声称已结算送货可以无条件作废。

物料池CSV可走现有“导入资料表”→选列→逐行确认流程；这只建档/关联，不生成库存。PDF中的采购方/供应方信息和条款用于展示，不表示应用已存储了这些字段。

## 给README制作与审阅者

可以使用两种语言的PDF、PNG和合成数据重新拍摄真实界面。请保留合成标记，使用当前界面，不用文档画面冒充产品已实现的字段；不宣称真实客户、生产部署、海外财务支持、OCR准确率或节省时间。生成器为 `generate.py`，需要报告制作依赖ReportLab及仓库中的OFL字体，不属于应用运行依赖。
