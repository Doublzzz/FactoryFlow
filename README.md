# FactoryFlow / 交有数

简体中文 · [English](README.en.md)

小工厂的订单与交付工作台：收单、分批送货、看清待交，再与客户对账。离线安装包的业务数据和图片识别都在本机处理，无需上传云端。

**Windows 开发者预览**

![分批送货后的待交清单，保留各行单位和数量（合成演示）](docs/images/readme/zh-03-open-lines.png)

同一张合成订单：120 件交了 30 件，剩 90 件；35.5 千克交了 10.25 千克，剩 25.25 千克。不同单位分别计算。

## 下载试用

Windows 10/11 x64：到 [v0.1.0-preview.1 预览版本](https://github.com/Doublzzz/FactoryFlow/releases/tag/v0.1.0-preview.1)下载 `FactoryFlow-Windows-x64-v0.1.0-preview.1.zip`（约 174 MB）。

1. 完整解压 ZIP，双击 `安装.cmd`，按提示阅读第三方组件条件并完成安装。
2. 打开桌面的 FactoryFlow 入口，首次启动时设置工厂名称和本地账号。
3. 先用[合成采购单](samples/purchase-orders/README.md)试一遍录单、分批送货和对账。

包内带有 Python、数据库和本地 OCR 模型，无需另装 Python、Node.js 或 PostgreSQL；下载并解压后，核心业务可离线运行。安装、备份和故障处理见[离线使用说明](docs/FACTORY-OFFLINE-GUIDE.txt)。同版源码、第三方源码材料和 `SHA256SUMS.txt` 都在上述版本页面。

## 从第一张订单开始

不必先整理完整客户库或物料库。客户可在录单时新建，订单也能不关联物料直接确认；有重复订单后，再把需要复用的行收录进物料池。

![从第一张订单开始：录单时新建客户，人工核对后生成订单，物料以后再整理（合成演示）](docs/images/readme/zh-first-order.gif)

合成演示，24 秒节选、0.5 倍速；省略了识别等待和部分逐项核对。[完整演示说明](docs/README-SCREENSHOTS.md)

1. **收单与核对**：上传图片/PDF，人工对照原件检查候选；也可直接手工录单。
2. **分批送货**：按订单行记录本次送货，查看已交和待交；作废保留历史并回退原数量。
3. **客户对账**：从送货明细建立草稿，记录发送依据和客户反馈，区分认可、待核对与暂缓数量。
4. **固定本期结算**：确认选定数量与金额，显式承接符合条件的后续余额，保留早期证据。
5. **整理输出**：导出内置或客户模板 Excel，整理订单原件、送货副本和对账文件。

![对照采购单人工补齐和校正后的四行候选，仍需确认生成订单（合成演示）](docs/images/readme/zh-02b-manually-reviewed.png)

上图是人工核对后的候选；识别只提出候选，表格解析仍不稳定，需要对照原件校正或补录。[原始提取结果与截图说明](docs/README-SCREENSHOTS.md)

[中英文合成采购单](samples/purchase-orders/README.md)包含原件预览与参考明细。公司、联系人、标识和交易数据均为虚构，不含真实客户资料。

## 几个产品取舍

- **业务动作由人确认**：提取只提出候选，确认后才成为订单；客户认可与正式结算也是独立动作。
- **物料随订单积累**：物料池记录我方/客户料号，支持人工建档和核对后的 xlsx/UTF-8 CSV 导入。建档不产生库存，后续关联不改写已确认的原单字段。
- **数量和历史要准确**：保留原单位，数量与金额使用精确小数；确认版本不可变。每个业务事务同时提交审计、幂等结果和账本效果。

## 当前支持与限制

网页支持简体中文和 English；新内置对账 Excel、送货即时打印支持英文。切换语言保留客户名称、料号、备注和原件文字；客户模板保留原文，归档送货副本仍使用中文规则。

当前仅支持 **CNY**。客户认可和正式结算不代表收到付款；对账单与送货单不是税务发票。库存、付款处理、多币种和海外税务不在当前能力内。

这是开发者预览，尚未通过生产或工厂实际使用验收。已完成的工程检查见[验证记录](docs/VERIFICATION.md)；干净 Windows 安装、原生 Excel、实体打印和真实资料兼容性仍需验收。请使用新的试用数据目录，本版不提供已有业务库的原地升级。

离线包供本机使用，不提供局域网多人访问。备份和导出文件仍含业务资料，需要自行妥善保管。构建输入与第三方材料见[分发说明](docs/DISTRIBUTION.md)。

## 本地开发

从源码开发需要 Windows、Node.js 24（准确约束见 `package.json`）、uv、Python 3.14 和独立 PostgreSQL，首次安装开发依赖需要联网。按[本地运行说明](docs/LOCAL-OPERATIONS.md)完成依赖、配置、显式迁移与首个本地账号，再启动服务；启动本身不会自动迁移或重置数据。仅试用安装包不需要准备这些开发工具。

前端与合同检查命令（需先准备开发环境）：

```powershell
npm run typecheck
npm run contracts:check
npm run build
```
