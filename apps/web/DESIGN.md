# UI design conventions

Use the current product layout as the baseline. Explain operations through hierarchy, alignment and interaction. Preserve units, business meanings, statuses, errors and accessible names; remove redundant guidance only when it does not help a decision.

- Chinese brand: 交有数; English brand: FactoryFlow. Use clear factory-order and delivery context.
- Deep-blue navigation, light content surfaces and an indigo primary action. Delivered and outstanding quantities remain visually distinguishable; pair color with text and numbers.
- Keep customer/order identity above its item rows. Align exact decimal quantities with their labels and units. Pagination counts describe only loaded items.
- Place source document and review fields together; use a vertical flow on narrow screens. Keep primary actions visible without outer-page horizontal overflow.
- Use the bundled licensed Noto Sans SC with system fallbacks. Respect reduced motion and visible keyboard focus.
- Preserve loading, disabled, empty, failure, authentication and unknown-command-result states. Language changes must not clear drafts or alter a pending command.
- File organization uses explicit rule/file selection, preview, confirmation and generation. Changing the inputs invalidates the preview. Fixed historical paths/versions remain distinct from current source status.

Validate with desktop and narrow browser views, keyboard/accessibility names and relevant business scenarios. Visual improvements must not imply factory acceptance or measured productivity gains.
